---
name: No-auth public course
description: Permanent public-access rule for the Prompt Engineering course.
---

The course must have no login system: no Google OAuth, account controls, auth endpoints, user identity checks, output quota, or sign-in modal. All course and AI learning features are public and unmetered.

**Why:** The user explicitly and emphatically mandated removal of all login.

**How to apply:** Keep only anonymous browser sessions for public course progress and once-per-session visit counting. Do not reintroduce authentication or a login-triggered AI limit. Preserve every non-login feature: diagnostics, detection, grader/admin tools, AI features, downloads, and visitor totals all remain available without authentication. Visitor totals are public because there is no owner identity.
